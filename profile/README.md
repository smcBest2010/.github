## 🚀 지금 당장 시작해야 하는 것

### 1. Git과 GitHub

GitHub는 단순히 코드를 저장하는 사이트가 아님.  
내가 무엇을 공부했고, 어떤 프로젝트를 만들었으며, 얼마나 꾸준히 활동했는지를 보여주는 기록임.

다음 내용부터 공부하는 것을 추천함.

- 저장소 생성 및 복제
- `add`, `commit`, `push`, `pull`
- 브랜치 생성과 병합
- Pull Request 사용
- 충돌 해결
- README 작성
- Issues와 Projects 활용

📚 추천 강의: [코딩애플 Git & GitHub](https://codingapple.com/course/git-and-github/)

### 2. 프레임워크 하나

처음부터 여러 프레임워크를 공부하려고 할 필요는 없음.  
관심 분야에 맞는 하나를 선택해서 프로젝트를 완성하는 것이 중요함.

| 관심 분야 | 추천 기술 |
|---|---|
| Python 웹 개발 | Flask |
| JavaScript 백엔드 | Express.js |
| TypeScript 백엔드 | NestJS |
| Java 백엔드 | Spring Boot |

기술 이름만 알고 있는 것은 실력이 아님.

로그인, 데이터베이스, API 등의 기능을 직접 구현하고 가능하면 배포까지 해봐야 함.

### 3. AI 활용 능력

AI와 경쟁하려고 하면 안 됨.  
앞으로 경쟁하게 될 상대는 AI 자체가 아니라 **AI를 나보다 잘 활용하는 사람**일 가능성이 높음.

추천 도구는 다음과 같음.

- ChatGPT
- Claude
- Codex
- NotebookLM
- Notion

AI가 작성한 코드를 그대로 복사해서 제출하면 안 됨.

- 코드가 어떻게 작동하는지 알아야 함
- 왜 이 방법을 사용했는지 설명할 수 있어야 함
- 오류가 발생하면 직접 수정할 수 있어야 함
- AI의 답변이 틀렸는지 확인할 수 있어야 함

> **설명할 수 없는 코드는 아직 내 코드가 아님.**

## GitHub 계정 만들기

이미 GitHub 계정이 있다면 이 단계는 넘어가도 됨.

1. [GitHub](https://github.com/)에 접속함
2. 오른쪽 위의 `Sign up`을 누름
3. 이메일 주소와 비밀번호를 입력함
4. 사용할 GitHub 사용자 이름을 정함
5. 가입한 이메일로 전송된 인증 메일을 확인함
6. 이메일 인증을 완료함

GitHub 사용자 이름은 앞으로 프로젝트와 포트폴리오에 계속 표시될 수 있으므로 너무 장난스럽거나 복잡한 이름은 피하는 것을 추천함.
참고로 Github는 이 분야라면 무조건 쓰게될거임 그래서 Git도 배우라는 말이고

> **이메일 인증을 완료하지 않으면 저장소 생성이나 조직 가입 과정에서 문제가 생길 수 있음.**

## GitHub 프로필 기본 설정하기

계정을 만들었다면 최소한의 프로필을 설정해야 함.

1. GitHub 오른쪽 위의 프로필 사진을 누름
2. `Settings` 또는 `Your profile`로 이동함
3. 프로필 사진과 이름을 설정함
4. 자기소개에는 관심 분야를 짧게 작성

Backend Developer를 목표로 공부하고 있는 1학년 학생입니다.
